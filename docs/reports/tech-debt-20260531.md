## 2. Security Vulnerabilities (Priority 2)

All vulnerabilities are in **dev dependencies** (build tools and test runners). They do not affect the shipped `main.js` plugin bundle. However they pose risk to the developer environment.

### High Severity (3)

| Package | Vulnerability | Path | Patched In |
|---|---|---|---|

| `vite` | `server.fs.deny` bypass with query strings | `vitest > vite` | Latest |

### Moderate Severity (5)

| Package | Vulnerability | Path |
|---|---|---|
| `esbuild` | Cross-origin request acceptance in dev server | Direct dependency |
| `picomatch` | Method injection in POSIX character classes | `typescript-eslint` transitive |
| `vite` | Path traversal in optimized deps | `vitest > vite` |
| `postcss` | XSS via unescaped `</style>` in stringify output | `vitest > vite > postcss` |
| `brace-expansion` | Large numeric range bypasses DoS protection | `eslint > minimatch` transitive |

### Recommended Actions

1. `pnpm update vite vitest --latest` — resolves 4 vulnerabilities
2. `pnpm update esbuild --latest` — resolves 1 vulnerability
3. `pnpm update eslint --latest` — resolves brace-expansion
4. The picomatch and postcss fixes will follow from vite/vitest updates transitively
