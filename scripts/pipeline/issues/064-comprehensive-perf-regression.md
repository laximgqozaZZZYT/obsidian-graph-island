## Description
ユーザーから4つの場面でパフォーマンス低下の報告:

1. **初回起動時の読み込みが遅い** — プラグイン起動からグラフ表示完了まで

3. **ズームイン・ズームアウトが遅い** — ホイール/ピンチ操作時のフレームレート低下

- レイアウト再計算のメインスレッドブロック時間
- 不要な再描画（dirty flag管理の不備）
