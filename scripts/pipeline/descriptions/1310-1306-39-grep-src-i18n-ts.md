## Description (subtask of 1306-i18n-hardcoded-strings)

src配下で `setText\(["']` `textContent\s*=\s*["']` `createEl\([^)]*text:\s*["']` のパターンを
  Grepで網羅し、t()未経由のuser-facing文字列を全件リストアップする (CLAUDE.md準拠)。
  各文字列に対応するi18nキー (例: `panel.section.layout`, `toolbar.button.export`) を
  src/i18n.ts の en/ja 両方に追加する。この時点ではsetText側は未変更でビルドは通る状態を維持する。
  作業ログとして、特定したファイルパス・行番号・追加キー名の対応表をコミットメッセージに含める。
  src/i18n.ts は God Object 対象外だが、追加するキーは論理グループ単位でまとめて配置する。
