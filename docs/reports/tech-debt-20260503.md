## 4. Security Audit (P1)

`pnpm audit` reports **7 vulnerabilities** — all in devDependencies (no production
exposure). Severity breakdown: **3 high / 4 moderate**.

| Severity | Package | Vulnerability | Fix |
|----------|---------|---------------|-----|
| 🔴 High | `picomatch` | ReDoS via extglob | Upgrade |
| 🔴 High | `vite` | `server.fs.deny` bypass with queries | ≥ current patch |
| 🔴 High | `vite` | Arbitrary File Read via dev server | ≥ current patch |
| ⚠️ Moderate | `esbuild` | Cross-origin request via dev server | Upgrade |
| ⚠️ Moderate | `picomatch` | Method injection in POSIX char classes | Upgrade |
| ⚠️ Moderate | `vite` | Path traversal in optimized deps `.map` handling | ≥ 8.0.5 |
| ⚠️ Moderate | `postcss` | XSS via unescaped `</style>` in stringify | ≥ 8.5.10 |

**Impact**: All vulnerabilities are in the build/test toolchain (`vitest` → `vite`,
`postcss`, `esbuild`). They cannot be triggered in the shipped `main.js`, but they
affect developer machines running `pnpm test` or the dev server.

**Action**: Run `pnpm update vitest vite postcss esbuild` and re-audit.

to the PR gate script if not already present. Cannot enumerate warning categories
