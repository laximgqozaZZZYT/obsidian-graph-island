## Description (subtask of 1376-hover-similar-suggest-top3)

src/utils/find-similar-nodes.ts を新規作成し、`findTopSimilarNodes(target: GraphNode, candidates: GraphNode[], edges: GraphEdge[], topN: number = 3): { node: GraphNode; score: number }[]` を export する。
  類似度の特徴量は「対象ノードの隣接ノード ID 集合」を Set として構築（src/utils/jaccard-similarity.ts の `jaccardSimilarity` を使用）。
  仕様:
  - target 自身は結果から除外
  - スコア 0（共通隣接0）のノードは除外
  - スコア降順でソートし、同点時は node.id の昇順で安定化
  - topN 件まで返す（候補不足時は実数のみ返す）
  GraphNode/GraphEdge 型は src/types.ts から import する（型定義の追加・変更は禁止）。
  tests/utils/find-similar-nodes.test.ts を新規作成し、以下を網羅:
  - 隣接ノード共有によるスコア計算（手計算した値と一致）
  - target 自身が結果に含まれないこと
  - スコア0のノードが除外されること
  - topN=3 の上限が機能すること（候補が5個以上のとき3件に切り詰め）
  - 候補が topN 未満のとき返却数が候補数と一致
  - 同点時の id 昇順タイブレーク
  既存ファイルへの変更は禁止。
