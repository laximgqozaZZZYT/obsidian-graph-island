## Description

ユーザー報告:
- 現状より軽くしてほしい
- 使いやすくしてほしい
- 操作性がいまいち

以下の手順で対応すること:

### Phase 1: E2Eテストで問題点を洗い出す
1. CDP経由でプラグインを起動し、実際の操作を再現
2. 以下の観点で問題を特定:
   - 初期表示までの時間 (2000+ノード)
   - ズーム/パン操作のレスポンス (フレーム落ちの有無)
   - レイアウト切替時の遅延
   - パネル操作 (設定変更) のレスポンス
   - ノードクリック/ホバーの反応速度
   - searchQuery 入力時のフィルタリング速度
3. smoke テスト + フルE2Eテストを実行し失敗するテストを特定

### Phase 2: パフォーマンス改善
1. doRender() の不要な再描画を除去
2. requestAnimationFrame の重複呼び出しを防止
3. D3 simulation の不要な再起動を抑制
4. 大規模グラフでのレイアウト計算のメインスレッドブロック軽減
5. edge rendering の最適化 (5000+エッジ時の描画コスト)

### Phase 3: 操作性改善
1. ズーム操作の滑らかさ (ホイールイベントの補間)
2. パン操作の慣性 (フリック後の減速)
3. ノードフォーカス時のアニメーション
4. パネル設定変更の即時反映 (debounce の適切な調整)
5. キーボードナビゲーションの改善

逆質問禁止。CDP経由で実際の動作を確認し、問題を特定・修正すること。
