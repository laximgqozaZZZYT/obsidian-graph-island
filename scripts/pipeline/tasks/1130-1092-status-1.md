## Description (subtask of 1092-1072-status-done)

目的: subtask-1 の編集が「frontmatter status 1行のみの変更」であることを git で検証する。

  手順:
  1. Bash `git status --short` を実行し、変更ファイルが subtask-1 で選定された1ファイルのみであることを確認。
     - 期待出力例: ` M issues/<選定ファイル>.md` の1行のみ
     - 他のファイルが含まれていれば即時失敗として報告
  2. Bash `git diff -- <選定ファイル>` を実行し、差分が以下の形式で status 1行のみであることを確認:
     ```
     -status: decomposed   (または -status: in-progress)
     +status: done
     ```
     - frontmatter 区切り (---) や他フィールドに差分が出ていれば失敗として報告
  3. 検証成功時は確認結果を報告のみ (コミット・push は行わない — 自律パイプラインの後段が処理)

  禁止:
  - 追加の編集 (検証のみ)
  - `git add` / `git commit` / `git push` / `git restore` / `git checkout`
  - `pnpm test` / `pnpm lint` の実行 (ソース/設定未変更のため不要)

  受け入れ:
  - `git status --short` 出力が当該1ファイルのみ
  - `git diff` が frontmatter `status` 1行のみ
  - 検証結果がレポートとして出力されている
