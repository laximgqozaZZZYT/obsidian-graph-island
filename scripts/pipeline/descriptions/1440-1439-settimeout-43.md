## Description (subtask of 1439-settimeout-leaks)

Grep で `setTimeout(` と `clearTimeout(` を全件列挙し、各 setTimeout 呼び出しが
  以下のどれに該当するかをファイル:行付きで分類する。

  既存の timer-tracker (5ef6863a で done になっているもの) があるか
  src/utils/, src/views/ を確認し、再利用可能なら採用方針を記録する。
  成果物: docs/timer-audit.md に「C 該当 N 箇所のファイル:行リスト」「再利用する
  timer-tracker のパスまたは無いことの確認」を記述。コード変更なし。
