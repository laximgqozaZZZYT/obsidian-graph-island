## Description (subtask of 1351-overview-label-too-small)

`src/views/LabelManager.ts` と `src/views/RenderPipeline.ts` 内で
  ノードラベルの最終描画フォントサイズを決定している箇所
  (例: `fontSize * worldScale` 形式の計算 / LOD によるラベル間引き) を
  読み込み特定する。zoom-out / autoFit でフォントサイズが極端に
  小さくなる原因を特定したうえで、`src/render-thresholds.ts` に
  `LABEL_MIN_READABLE_PX` のような閾値定数を追加する (CLAUDE.md の
  「ハードコード禁止」ポリシーに従い、しきい値は RenderThresholds に置く)。
  そのうえで `computeLabelScreenFontSize(rawFontSize, worldScale, minPx)`
  のような純粋関数を新規ファイル `src/views/labels/label-font-size.ts`
  に追加する。GraphViewContainer.ts / EdgeRenderer.ts / RenderPipeline.ts /
  PanelBuilder.ts の行数は増やさない (God Object policy)。
