## Description
Obsidian built-inのグラフビュー（コアプラグイン）は、ズーム・パン・ノード移動・
レイアウト遷移がすべて滑らかにアニメーションされる。Graph Islandでも同等の
シームレスなアニメーション体験を実現したい。

### 参考: コアプラグインのアニメーション特徴
- ズームイン/アウト: イージング付きスムーズズーム（ホイール1クリックで段階的に拡縮）
- パン: 慣性スクロール（フリック後に減速して停止）
- ノードドラッグ: 物理シミュレーションと連動した自然な追従
- レイアウト遷移: ノードが現在位置から新位置へ滑らかに移動（補間アニメーション）
- フォーカス: ノードクリック時のスムーズなカメラ移動

### 現状の問題
- ズームが瞬間的に切り替わりカクつく
- レイアウト変更時にノードが瞬間移動する（中間フレームなし）
- パンに慣性がない
- 全体的に「スナップ的」で滑らかさが不足

## Acceptance criteria
- [ ] ズーム: イージング付きスムーズズーム（requestAnimationFrame補間）
- [ ] パン: 慣性スクロール（velocity decay）
- [ ] レイアウト遷移: ノード位置の補間アニメーション（lerp/easing、300-500ms）
- [ ] フォーカス移動: カメラのスムーズ遷移
- [ ] 2000+ノードで60fps維持（アニメーション中も）
- [ ] アニメーション設定: 有効/無効トグル + duration調整（アクセシビリティ対応）
