## Description

各ノートのMarkdown本文中にインライン記法で関係を明示し、その関係をグラフ上のエッジとして表示する機能。

### 既存の関係表現との違い
- **タグ間継承関係** (ontology rules): タグベースの抽象的な関係定義
- **フロントマター related**: YAML frontmatterでの関係指定
- **本機能**: ノート本文中にインラインで具体的な関係を記述

### インライン記法の仕様
```
[[ノート名|表示テキスト]@関係名]
```

例:
- `[[孫悟空|悟空]@師弟]` → 「悟空」と表示し、現在のノートから「孫悟空」への「師弟」関係エッジ
- `[[フリーザ]@敵対]` → 表示テキスト省略時はノート名をそのまま表示
- `[[ベジータ|ベジータ王子]@ライバル]` → 「ライバル」関係としてエッジを描画

### グラフ設定での制御
- パネルUI (Display tab) にインライン関係の表示トグルを追加
- ON/OFF でインライン関係エッジの表示・非表示を切り替え
- エッジのラベルとして関係名を表示するオプション

### 実装に必要な変更
1. **パーサー**: `metadata-parser.ts` にインライン記法のパース追加
2. **データモデル**: `types.ts` の `GraphEdge` にインライン関係の edge type 追加
3. **レンダリング**: `EdgeRenderer.ts` でインライン関係エッジの描画対応
4. **パネルUI**: `PanelBuilder.ts` または `panel-sections-filter.ts` にトグル追加
5. **i18n**: 関連UIテキストの翻訳キー追加
