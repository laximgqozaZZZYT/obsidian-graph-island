## Security Audit Summary

`pnpm audit` reports **8 vulnerabilities** — all in `devDependencies` only (not
included in the production `main.js` bundle delivered to Obsidian users).

| Severity | Package | CVE / Advisory | Affected Path | Fix |
|----------|---------|----------------|---------------|-----|
| 🔴 High | `picomatch` | GHSA — ReDoS via extglob | `vitest > picomatch` | `>=4.0.4` |
| 🔴 High | `vite` | GHSA-4w7w-66w2-5vf9 — `server.fs.deny` bypass | `vitest > vite` | `>=8.0.5` |
| 🔴 High | `vite` | Arbitrary file read via Vite dev server | `vitest > vite` | `>=8.0.5` |
| 🟡 Moderate | `esbuild` | CORS request bypass in dev mode | `esbuild <=0.24.2` | `>=0.25.0` |
| 🟡 Moderate | `picomatch` | Method injection in POSIX character classes | `vitest > picomatch` | `>=4.0.4` |
| 🟡 Moderate | `vite` | Path traversal in optimized deps | `vitest > vite` | `>=8.0.5` |
| 🟡 Moderate | `postcss` | GHSA-qx2v-qp2m-jg93 — XSS via `</style>` | `vitest > vite > postcss` | `>=8.5.10` |
| 🟡 Moderate | `brace-expansion` | GHSA-jxxr-4gwj-5jf2 — DoS via numeric range | `eslint > minimatch > brace-expansion` | `>=5.0.6` |

> **Production impact: NONE.** These packages are only in the test/build toolchain
> and are not bundled into `main.js`. However, running `vitest` or `pnpm build` in
> a compromised environment with untrusted input could trigger these vectors.
