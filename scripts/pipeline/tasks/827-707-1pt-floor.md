## Description (subtask of 707-675-subtask)

subtask-1で特定した超過指標のみ、vitest.config.ts の `coverage.thresholds` を更新。
  新閾値 = Math.floor(現在値 - 1) (整数)。超過していない指標は一切変更しない。
  閾値の引き下げは絶対禁止（既存値より新値が小さい場合はスキップ）。
  例: B現在27.19% → floor(27.19-1)=26 → 25.5→26 に引き上げ。

  手順 (この順序を厳守):
  1. vitest.config.ts を編集（未コミット状態を保つ）。
  2. `pnpm test:coverage` を実行。
  3a. PASS → 独立コミット `chore: raise coverage thresholds (cycle XXX)` を作成し、
      `coverage/coverage-report.tmp.md` を削除。
  3b. FAIL → `git checkout -- vitest.config.ts` で未コミット変更をロールバックして中断。
