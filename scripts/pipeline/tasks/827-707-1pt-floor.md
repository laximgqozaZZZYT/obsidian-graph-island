## Description (subtask of 707-675-subtask)

subtask-1で特定した超過指標のみ、vitest.config.ts の `coverage.thresholds` を更新。
  新閾値 = Math.floor(現在値 - 1) (整数)。超過していない指標は一切変更しない。
  閾値の引き下げは絶対禁止（既存値より新値が小さい場合はスキップ）。
  例: B現在27.19% → floor(27.19-1)=26 → 25.5→26 に引き上げ。
  変更後、`pnpm test:coverage` を実行し全閾値 PASS を確認。
  PASS したら独立コミット `chore: raise coverage thresholds (cycle XXX)` で記録し、
  `coverage-report.tmp.md` を削除する。PASS しなければ変更をロールバックして中断。
